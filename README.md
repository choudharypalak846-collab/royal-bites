# ROYAL BITES – Restaurant Billing System

A Java-based Restaurant Billing System developed using Java Swing.

## Features
- Attractive restaurant menu with food images
- Add and remove food items
- Quantity selection
- Automatic bill calculation
- 5% GST calculation
- Customer name and table number
- Cash, UPI and Card payment options
- Printable customer receipt
- Order history
- Sales dashboard

## Technologies Used
- Java
- Java Swing
- AWT
- File Handling
- CSV

## How to Run
1. Install JDK on your computer.
2. Download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Compile the program:

   javac RestaurantBillingSystem.java

6. Run the program:

   java RestaurantBillingSystem
